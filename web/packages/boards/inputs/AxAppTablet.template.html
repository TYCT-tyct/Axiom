管理 Key 和 API Key 的区别

能做
  • 建 Key、改额度、停用和轮换
  • 查用量、余额和日志
  • 适合部署脚本：每个环境自动建一个 Key
不能做
  • 调用模型。调用模型要用普通的 API Key
  • 充值、改登录方式、注销账号
  • 看到别的 Key 的完整内容
