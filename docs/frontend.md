# 前端与设计

官网、用户控制台、管理后台三类页面要做什么、按什么标准验收、外观能改到什么程度。前端的技术选型见[总体架构的「技术选型」](architecture.md#技术选型)，站点的品牌和主题配置见[账户与租户的「站点」](domains/accounts.md#站点)。

## 要求

### 基线

- 页面内容以 OpenRouter 为功能基线，再突出 Axiom 要讲清楚的部分：端点实测的属性与依据、挂在 key 上的预设、按实际服务的端点计费的明细与免单标记。管理后台没有可参照的公开页面，内容从各领域文档推出。
- 参照的网站只是学习目标，不模仿；设计和内容都是 Axiom 自己的。
- 中文优先，英文同样讲究：两种语言都完整，都像母语。

### 验收门槛

任何一条不过，设计方案就打回：

- **无障碍**：WCAG 2.2 AA；文字对比度不低于 4.5:1；所有操作都能用键盘完成，焦点看得见；读屏软件能读。
- **换主题**：用纯红、纯黄、近黑、近白、荧光绿这类极端品牌色生成的深浅两套配色，全部达到上一条。
- **中英文**：两种语言都完整，不溢出；标识符按下面「表格与标识符」一条中间截断，其余文字不截断；数字、货币、日期按语言格式化。
- **极端数据**：超长名字、空列表、巨大数字、上万条记录都不破版。
- **尺寸**：360px 宽的手机到 2560px 宽的大屏都能用；控制台的核心任务在手机上能完成。
- **表格与标识符**：列标题不换行；长标识符在中间截断，保留首尾，悬停或聚焦可看到完整值，并可复制。窗口放不下时表格在自身框内横向滚动，不隐藏列；每行的操作列贴在框的右缘，始终在屏幕上。
- **动效**：动画一律播放，不随系统的"减少动态效果"设置关掉；动画不掉帧。
- **性能**：达到下面的前端性能指标。

### 可用性任务

找真人测，达到以下用时和步数：

- 新用户从首页到把 key 配进 Claude Code（不含付款）：不超过 3 分钟。
- 在模型价格页说出"哪个端点最便宜且已验证"：不超过 30 秒。
- 从调用记录找到一次失败的原因和每次尝试：不超过 2 次点击。
- 进控制台不点击就能看到余额和本月花费。
- 充值不超过 3 步；管理员在后台给用户加额度不超过 30 秒。

### 工程要求

- 构建产物的文件名带内容哈希，可以长期缓存；入口页从不缓存。
- 新版本上线后，开着的控制台和管理后台提示刷新；按需加载的代码块因为已经换了版本而加载不到时，自动刷新一次。
- 静态文件压缩后发送，流式输出不压缩。
- 只用国内也能访问的资源，能自己托管的都自己托管，字体也一样。
- 每个数据视图都有加载中、空、出错、没有权限四种状态；替换整个页面的状态（加载中、空也在内）都保留一个一级标题（加载中的标题是“正在加载”，视觉隐藏）；切换页面不出现空白。
- 一页里各自取数的区块，下面的等上面的有了结果才出现：先到的区块变高会把已显示的区块推下屏幕（CLS）。
- 数字和时间按语言和查看者的时区格式化，时间标出时区；按 UTC 定义的目标月份在控件旁写明 UTC。
- 页面在严格的内容安全策略下工作，没有需要 `unsafe-inline` 的内联脚本和样式。

### 前端性能指标

下表是目标。脚本与字体由 `web/scripts/budget.ts` 强制；运行时测量的实际门禁、方法和限制见[实测](#实测)。

| 指标 | 官网 | 控制台、后台 |
|---|---|---|
| 首屏主要内容出现（LCP） | 手机限速下不超过 2.0 秒 | 电脑不超过 1.5 秒，手机限速下不超过 2.5 秒 |
| 点击到画面响应（INP） | 不超过 100 毫秒 | 不超过 100 毫秒 |
| 页面跳动（CLS） | 不超过 0.05 | 不超过 0.05 |
| 首屏脚本 | 不超过 150KB；3D 另计，不超过 1MB，在页面可以操作之后才加载 | 不超过 200KB；每多打开一个页面增加不超过 50KB |
| 字体 | 每页西文和数字不超过 60KB；中文用自己托管、按页面裁剪的 MiSans，每页不超过 100KB，只预载首屏用字 | 每页西文和数字不超过 60KB；中文用自己托管、按页面裁剪的 MiSans，不预载，每页不超过 100KB |
| 长列表 | — | 加载 1000 行（列表按游标分页，一页 50 行，一万行不是页面会有的状态）滚动不掉帧 |

测量条件：

- "手机限速"用 Lighthouse 的移动端默认配置（模拟慢速 4G、CPU 降速 4 倍），"电脑"用它的桌面配置；
- 脚本按 brotli 压缩后的传输大小计，字体取 woff2 文件本身的大小（已压缩）；首屏还算入口页打开的页面（控制台的概览、后台的首页）；每页字体是这一页可能加载的字体文件去重后的和，首屏预载的字体另外报告；
- INP 用 Playwright 驱动常用操作（筛选、翻页、打开详情、提交表单），在 CPU 降速 4 倍时用 web-vitals 采集，每种操作取最差的一次；
- "不掉帧"在 CPU 降速 4 倍时，滚动长列表或播放动画 5 秒，看两项：在固定 60Hz 的测试环境里用 requestAnimationFrame 记录帧间隔，间隔超过 25 毫秒（1.5 帧，留出计时误差）算掉帧，掉帧不超过 5%；主线程没有超过 50 毫秒的长任务。调用日志和用户列表各加载 1000 行来滚，两者都是按游标分页、一页 50 行。开始计时前回到列表顶部并等版面稳定；计时中每一帧都确认 `window.scrollY` 在增加，移动的帧不到九成就算这次测量失败，避免把已经触底后的静止页面算成平滑滚动。

### 实测

`web/e2e/vitals.spec.ts` 对嵌入 Go 的构建产物测量，接口在浏览器内模拟，因此手机 LCP 不含真实接口那一跳。方法与基线的解释放在测试常量旁，历史运行数字不作为规范保存。

| 测量 | 当前门禁与方法 |
|---|---|
| 普通页 LCP | 手机回归上限 6 秒（目标仍为 2.5 秒），电脑上限 1.5 秒；登录、key、调用、余额、流水及后台用户、供应商、模型、价格、设置各三次，每次目标页夹在前后两次概览页之间、独立上下文；以参照平均值折算到基线，系数最多 1，取三次折算中位数；网络静默且一秒内没有画出更大的元素才读数，注解记下最大元素 |
| 概览 CPU | 两档均不降 CPU，Chrome trace 累加渲染主线程任务的 `tdur`，排除被换下的时间；PR/列车与 BASE 的概览交替加载九对，取每对比值的中位数 ≤1.25，本树 CPU 中位数另限电脑 1413ms、手机 1731ms；main 无 BASE 只报告 |
| CLS | 每页每档三次取最大值，上限即目标 0.05 |
| INP / 概览 LCP | 概览 LCP 三次中位数、INP 取操作最差值，只报告；INP 随共享宿主负载摆动，对话框的 INP 约一半是 `showModal` 让页面其余部分 inert 引起的整页样式重算，约 450 个元素逐个匹配约 1100 条规则，摊在全部样式表上，没有单条规则占大头 |
| 长列表 | 按上节取样，只报告掉帧与长任务；滚动有效性断言仍须通过 |

概览与基准用本树同一模拟接口，只比页面代码；不使用登录页或固定循环校准，因为不同工作量对抢占不等比例。CPU 不降速，因为 Chrome 的忙等会把宿主调度混入 CPU 时间；不用硬件指令数，CI 不为此开放 `CAP_PERFMON` 或 `CAP_SYS_PTRACE`。九对降低单次突发影响，绝对兜底防止逐次小退化累积；失败不重试。原始值、参照、折算、CPU 与比值写入测试输出和注解。

概览兜底的校准用 `node web/scripts/vitals.ts <服务地址> <输出目录>`：先 `just web-embed`，在另一个终端启动 `go run ./internal/platform/webui/cmd/serveweb localhost:18083 localhost:18084`，等构建和其他检查结束，再以 `http://localhost:18083` 为地址串行测量。工具复用门禁的模拟接口、标题等待、独立上下文、网络限速及 `toplevel` trace；电脑、手机不降 CPU 各九次，以各自中位数向上取整到毫秒再乘三。手机另测九次 4× CPU，仅供诊断，不用于兜底。每档第十次单独记录 timeline 和 JS 采样，写入 `.trace.json`，可导入 Chrome 性能面板；详细 tracing 有额外开销，不能拿它的总时间校准。环境、九次原值和 DOM 统计写在同一输出目录；本地输出放 `web/test-results/`，不入库。

2026-11-17 的同机比较（每格为九次中位数及最小—最大，单位 ms；手机前一列不降 CPU）：

| 产物 | 电脑 | 手机 | 手机 4× CPU（含忙等） |
|---|---|---|---|
| #826 前一提交 `8f4a7aa1` | 512（411—949） | 674（533—1379） | 2523（2296—2770） |
| 移植后的 `b7e5225f`，本次改动前 | 479（423—884） | 570（509—776） | 2489（2347—2601） |
| 本次校准，Go 嵌入产物；页面源码未改 | 470（410—783） | 577（539—682） | 2321（2019—2383） |

前两行都是生产构建由 Vite preview 提供，复用同一模拟接口；它们的范围重叠，不能据此认定 #826 带来了三倍回归。旧 340/400ms 校准写于 11 月 5 日，早于后续外壳与页面改动。[退队运行 44176887944](https://github.com/TYCT-tyct/Axiom/actions/runs/44176887944) 实际的电脑中位数是 1034ms（922—1347），手机是 1120ms（762—1463），手机配对比值 0.937；电脑在绝对断言处先失败，未输出比值，不能把手机的 1096ms 基准当作电脑的基准。

最终校准的本机为 8 核 Linux、AMD EPYC、Chromium 156.0.8078.4；测量时没有本次构建或检查并行，但共享宿主不保证完全空闲，环境文件保留了负载。中位数向上取整为 471/577ms，三倍即 1413/1731ms，配对比值上限仍为 1.25。没有改页面或区域来制造降幅；三批的差异包含宿主波动及服务方式变化，不是优化收益。

#### 控制台首屏的剩余开销

手机档（慢 4G、4× CPU）首屏代码约 1.6 秒到达，之后主线程串行：模块解析与编译（V8 `ParseProgram`/`ParseFunction`/`PreParse`/`CompileCode`）约 300—400ms，外壳在会话前后各渲染一次，再是页面渲染与数据到后的渲染，每次渲染后布局约 100ms。已去掉的是剖析里归属明确的部分：首个 Intl 格式加载引擎数据（`theme.js` 在代码下载时预热）、画板 `boardStyle` 每次渲染建样式表（按文本缓存）、调用页汇总等 50 行一起渲染（行另起一次渲染），合计把 `format.ts`、`dom.ts` 在首屏的 JS 时间从每页约 100—250ms 降到 25—80ms（4×，采样剖析）。key 对话框的点击只渲染对话框，不再重渲染整页列表：不降 CPU 时点击任务中位数创建 50→39ms、修改 52→45ms；其余约 20ms 是 `showModal` 让页面 inert 的整页样式重算（约 450 个元素，外壳占 263 个，其中图标的填充副本 96 个），约 20ms 是表单渲染。

还要的做法和代价：手机 LCP 要再省约 0.1—0.2 秒，只剩减少首屏字节和主线程总量，即按视口只加载一种外壳及其样式（实测只拆外壳时手机首屏脚本少约 4 kB、样式少约 39 kB 未压缩，LCP 变化在本机噪声内，没有保留）、按语言拆文案并预载、把画板图标的描边/填充两份合成一份；INP 要再省约 20%，需减少外壳常驻 DOM（关闭的弹层、图标副本），这要改画板转换器，属已批准画面的结构改动。

两档 SVG 后代均为 10：模拟调用在 10 月，当前月为 11 月，聚合为空，因此此次门禁没有绘制数据柱，不能据此保证完整月份数据下的成本。

计时独立串行运行，路径选择见 [CI](ops/ci.md#作业与路径门禁)。logo 的 CLS 由 `web/e2e/logo-cls.spec.ts` 独立守护：1×1、1024×1024、1024×1、1×1024、延迟 800ms 与 404，分别在 1280px/360px 的登录页和外壳检查；logo 槽位及随它移动的名称位移必须为零。

## 设计

### 设计原则

1. **改不坏**：换任何站点、颜色、语言、数据量，页面都成立。
2. **数字有出处**：价格、速度、成功率、质量分都能看到依据和时间。
3. **状态先于功能**：余额、花费、key、报错一眼可见；出了问题直接给出原因和下一步。
4. **中文优先**：中文按中文的排版规矩来，英文同样讲究。
5. **一处惊喜，处处克制**：每个页面只有一个招牌时刻；常用操作不加动画。

### 主题与自由度

外观是主题，不是每个站点各做一套页面：

- **页面结构只有一套**。控制台和管理后台只换颜色和 logo。
- **站点 logo**：站点在后台设置页上传、更换或清除 logo（SVG 清洗后保存，或受限的 PNG/WebP；存储和清洗规则见[账户与租户](domains/accounts.md#站点)）。控制台的侧栏、登录页和 1024px 以下的顶栏显示 `getSite` 给的 `logo_url`，官网页头也读同一个公开接口；没有 logo 或图片加载失败时显示站点名称和自带的标记。图片固定 20×20、`object-contain`，加载前后不改变布局，极端长宽比也不撑开页头（`web/e2e/logo-cls.spec.ts` 核对，见「实测」）。管理后台的登录页和侧栏同样显示站点名称和 logo（公开的 `getAdminSite` 在管理域名给出地址），设置页只用后台返回的 data URL 预览当前 logo；页面标题和导航仍表明这是管理后台。
- **首页是一个插槽**：站点配置里从几套首页设计中选一套。第一版只做 Axiom 自己的首页；给二级站点用的首页模板，等开放二级站点时再做。
- **颜色自动配比**：站长选一个品牌色，或上传 logo 自动取色，系统生成浅色、深色两套完整配色；成功、失败、警告色自动避开品牌色，并且始终配图标。没有配置时用自带的浅色、深色两套（强调色默认青色 cyan）。配色由 `packages/ui/src/brand.ts` 的 `brandStyle` 生成。它输出 `--accentSolid`（填充和焦点，对相邻底色不低于 3:1）和 `--accentT`（文字，对页面、面板、卡片底色以及两种中性色上的 `--accentWash` 不低于 4.5:1，标签、头像、key 徽标把强调色文字放在浅底上），按画板重做的页面（官网各屏在内）读这两个；另有七个旧令牌（`--accent`、`--accent-ink`、`--accent-soft`、`--accent-line`、`--btn`、`--btn-ink`、`--btn-line`）给尚未重做的页面，随 #747 的后续卡删除；其余强调色在 `tokens.css` 里用 `color-mix` 推出，只有不是 `#rrggbb` 的写法会被拒绝，其余颜色被调整而不是拒绝。**主按钮不跟品牌色**：它是中性的最深一档（sand12），品牌色只出现在强调、链接、焦点和选中。中性色按应用分：控制台和后台用 sand，官网用 slate，由根元素的属性选择。站点契约为 `brand_color`，由后台 `/sites/{site_id}/brand` 设置、控制台 `GET /site` 读取，`AppShell`、`AuthFrame` 和官网的 `useSiteBrand` 通过 `useBrandStyle` 把它写到文档根元素（`<html>`），渲染在页面之外的恢复码对话框也继承同一套变量；字段缺省或旧节点不返回时用默认配色。
- **高对比主题**：用同一套机制，调高对比度参数生成。
- **用户个人**：可以选浅色、深色或跟随系统，再加一个自选主题色；站长可以关闭这项。
- **不开放**：字体、字号、间距、动效节奏。以后要开放，也只给几套精选组合。
- **官网也跟随站点**：模型与价格页、接入文档从第一版起使用站点的配色。
- **3D**：只用来表达产品本身；首屏不等 3D 加载；低端设备、省电模式时换成静态画面；没有 3D 美术资源时，只做程序生成的 3D。

### 视觉方向

第一版的默认外观取自负责人批准的设计稿（画板：官网 Site 与手机版、控制台 AxApp 的浅色、深色、平板、手机版、AxSpec 规范；按它迁移中，见 [#747](https://github.com/TYCT-tyct/Axiom/issues/747)）。结论：

- **字体**：西文和数字用 Instrument Sans（官网和控制台共用一个 400–600 的可变文件），等宽用 JetBrains Mono（静态 400），官网的衬线标题用 Instrument Serif Italic（关键词）和思源宋体（中文衬线，只用于 h1、h2 和登录标题）；中文正文用 MiSans，官网、控制台和后台都用。字体文件一律自己托管，管线和预算见[字体](#字体)。
- **颜色**：深浅两套；一个强调色，青色（cyan）；中性色控制台和后台用 sand（暖灰），官网用 slate（冷灰）。颜色只写在 `tokens.css`，每个颜色用 `light-dark()` 一次写出浅、深两个值。控件边界、焦点、选中的对比度见[对比度令牌](#对比度令牌)。
- **排版**：分两套，见[排版](#排版)。
- **首页**：导航、主视觉，然后六屏——接入、模型与线路、三步开始、上生产前、常见问题、海底。主视觉和海底屏是字符画的海（ASCII 海，canvas 绘制），海底屏同时是页脚：只列站点有页面的链接，保留 MiSans 署名；首页的数字（价格、延迟、成功率）能从公开接口取的用真数据，取不到的标「示例数据」或删掉（见「内容规则」）。首页每句话对任何站点配置都要成立：计费、回退和 key 可用模型的说法按[计费](domains/billing.md)、[路由](domains/routing.md)、[账户](domains/accounts.md)写成有条件的，说到服务时用站点名；站点配置在布局之上只问一次（跨断点不重问，从浏览器缓存恢复时重问，网络或服务端失败时按退避重试）；注册入口按 `getSite` 的注册方式（与控制台注册页同一判定 `registrationOf`）：开放照常，邀请制写明要邀请码；关闭，或站点还没应答、请求失败时，只给无条件成立的入口：页内入口去登录，导航栏、岛、菜单和首屏的注册按钮去掉。页脚的「价格」在站点不公开价格时（公开模型接口不带价格）去控制台的模型页，否则去 `/models`；首页只有一份公开模型的结果（含状态和取到的时间），模型屏和页脚都读它，任何一处重试成功都一起更新，换布局重建的屏沿用原时间。手机菜单关闭时 `inert`，打开时焦点进菜单，Esc 或关闭回到菜单按钮，选了某屏则落到那一屏。内容从中转站的优点和机制出发，不用概念插画。
- **登录**：留在控制台应用的 `/console/sign-in`（以及 `/register`、`/verify-email`、`/mfa`、`/consent`、`/reset-password`），不搬到官网。官网的登录按钮按下后，按钮碎成方块流向屏幕右侧（转场 `tiles` 的出发段，约 0.5 秒），然后跳转 `/console/sign-in`；登录页宽屏左海右表单，海里的鲨鱼聚到中央凝成随步骤变换的 3D 瓦片体（邮箱/同意是信封、密码/通行密钥是钥匙、验证码是六孔锁、完成是勾环），面向指针和焦点输入框，拒答时抖动，静置 20 秒散回鲨鱼再重聚；手机端海面为顶部 208px 窄带、右侧放小瓦片体；从官网点过来时标题解码一次，直接打开时没有。登录流程按真实接口：邮箱 → 密码 → `signIn`，需要第二因素时进 `mfa`，第一步旁放通行密钥和站点配置的第三方登录；注册按站点是邀请码还是开放注册区分。登录类页面一次只有一个请求在途（密码、第三方、通行密钥、两步验证的码、同意条款、退出），在途时整页锁住：表单、海面上的链接和语言切换都设为 Cookie 的响应一律先取消还在途的会话读取、再向服务端重读会话，页面不显示与 Cookie 不一致的状态；从往返缓存恢复的页面直接重新加载。两步验证这一步按待验证会话区分，同一人在别处重新登录得到新会话时从头开始；会话说明没有验证器（`totp_enabled` 为 `/token` 拒绝的令牌）、邮箱已被注册、邮箱域名已不被接受、没收到答复后都按上面的方式去登录；链接无效、域名不被接受和没收到答复时还可以重新注册，和登录入口一样要先确认浏览器未登录（注册页会把已登录的浏览器送走）。改变数据的请求遇到无响应或任何 5xx，页面都说明可能已经完成，不当作表单错误让人重发。字段只在空着、被服务端拒绝（邮箱、邀请码、密码长度）时标为无效，限流和服务暂不可用只是表单提示；同一个失败只在一处说，字段有提示时不再显示旧的表单提示，改一个字段只清掉它自己的错误，退回表单时不留上一次的答复。画板没画的步骤（密码、两步验证、同意条款、设置新密码、邀请码注册、设密码验证邮箱）用画板部件组合；条款正文用 `@axiom/ui` ### 排版

两套规则分开：

- **产品界面**（控制台、后台、官网的模型页和文档页、登录表单）：字号只有 12/14/16/24（行高 18/22/24/32），字重只有 400 和 500。
- **官网展示字**（首页、登录页左侧、转场）：展示字号 28/32/40/48/64/72/80，h1 是 `--dsp`，手机、平板、电脑分别为 40/64/80；字重 400/500/600，600 只用在品牌字、非中文的 h1 和所有衬线标题。Instrument Sans 带 `size-adjust: 105%`，让它和回退字体等高。
- 金额、用量、延迟和其他要纵向比较的数字一律用等宽数字（`font-variant-numeric: tabular-nums`），与用哪个字体无关。
- 字体按实际用到的字重裁轴：Instrument Sans 一个 400–600 的可变文件；JetBrains Mono 只要静态 400；中文正文现在只裁 400（500 的字由覆盖爬取决定，见「决策与理由」）；衬线只要 600。

### 字体

- fontTools 仅开发机运行，Python 依赖带哈希固定；按 URL/SHA-256 下载源到仓库外缓存，压缩源取清单指定文件，校验失败即停。源不入库、生成 woff2 入库且重跑逐字节一致，CI 不依赖 Python。
- MiSans VF 的 Regular 轴值 330 对应 CSS 400（轴 150–700、Medium 380）；每应用独立字形，官网 `Axiom CJK`、控制台 `Axiom CJK Console`、后台 `Axiom CJK Admin`；控制台的登录、两步验证和条款页例外，它们穿 Login 画板，画板写的是官网的 `Axiom CJK` 和 `AX Serif`，这几页就按这两个字体裁剪、不加载 `Axiom CJK Console`，收字含 Login 画板区域里渲染的译文。分片按页面标记预载（`fonts.json` 的 `preload` 列出页面），与官网共用的分片只在官网首屏预载。各应用 main.css 将 `--family-ui` 设为自身栈，正文与 font-sans 都读它；默认 local 栈不含裁剪中文。字形不跨应用共用，避免接口文字触发其他应用的分片。
- 字符来自中文翻译和页面所用键；控制台/后台沿 import 与实际用到的导出追踪键、点前缀、模板固定前缀，官网页在 sources.json 列出：模型页是单独的文档，它的键从 `site/src/models.tsx` 运行的代码追踪（`entries`），不收首页的文字；`site/first` 是首屏用字，单独成片，官网共用的入口页只预载它。按画板切出的区域把文字放在自己的 `<Name>.zh.ts`/`.en.ts`，不在应用的翻译里：一页收它（连同共用外壳）实际运行的区域的全部文字，包括区域组件直接写在标记里的字（如示例 key 的「•」），不收别的页的区域。覆盖爬取尚待交付：按计算字体/字重收字，跳过 `data-user-content`，再决定 500 与衬线分片；目前只静态取字、中文 500 用 400 显示，不合成粗体。字体保留 hinting，避免小字号字距不匀。
- 按「哪些页面用到此字」切片，一个字只属一个文件，再按总代价合并：文件表约 0.5KB、请求按 1KB，兼顾本页下载和全字形最坏情况，只在合计更省时合并。`coverage.test.ts` 检查每页字覆盖、管线输入指纹与产物；源缺字记录 absent 并回退。
- 预算见[性能指标](#前端性能指标)，十进制 KB；fonts.json 按本页字形全部文件去重求和，因为接口文字能触发任意片，另报告文案子集。缺文件也失败。仅官网预载清单标记的首屏中文正文，入口必须恰好匹配；控制台后台不预载。

### 动画

所有动画有一个所有者（海、首屏入场、语言与深浅切换、官网外壳、各屏、转场、登录页的方块、控制台的 CSS 动画），遵守同一套生命周期：

- **加载**：首屏内容出现之后才加载（`web/packages/fx` 的 `useEffectModule`：浏览器报告首次内容绘制后安排空闲加载，缺少 Paint Timing 时用首帧回调安排）。海和入场一起在首屏之后加载，每次访问在 `tide`（潮起）和 `decode`（解码）间随机选一种（`hero-enter.js` 默认规则）：`tide` 只升起海而不让首屏字再浮现，`decode` 逐格解码标题与词条；切语言或深浅前先结清进行中的入场。语言和深浅的效果在第一次按下其中一个按钮时加载，各屏的逻辑在接近视口时加载，转场在第一次按下登录按钮时加载，海的彩蛋在海起来之后加载，鲸在触发时加载。模块加载失败时页面照常可用，没有未处理的错误。
- **暂停**：标签页隐藏或所有者的元素滚出视口时暂停；所有持续的 JS 动画走同一个帧循环（`web/packages/fx` 的 `own`），它的计数器在 `window.axiomFx.state`，卸载后计数归零、监听器移除。画板的引擎（`web/packages/boards/src/engines`）原样运行，只换掉由谁驱动：海的帧和入场的进度来自共用循环；语言的解码和深浅的下潜只在播放的一两秒里用自己的帧。
- **文字的所有者**：语言切换的引擎就地改写页头和首屏的字（逐字解码），所以 React 只在挂载时按打开页面时的语言写这些字一次，之后不再写；其余的字照常随语言更新。
- **减少动态**：页面不读 `prefers-reduced-motion`（脚本的 `matchMedia` 和 CSS 的 `@media` 都不读），官网、登录页、控制台和后台的动画在任何系统设置下都照常播放：这是负责人的产品决定，沿用设计交接说明里「不做减少动态版本、一律播放」的规定。设计稿 CSS 里的 `prefers-reduced-motion: reduce` 规则由画板转换（`pnpm boards`）去掉；画板演示自己的脚本不进产品页面，原样保留。
- **CSP**：源码里不使用 `innerHTML`、`outerHTML`、`insertAdjacentHTML`、`cssText`、`setAttribute('style')`（`cssText` 的 setter 在 CSP3 里属于 `unsafe-eval` 一类）；单个样式属性的 CSSOM 写法可以用；SVG 资源里的 `style` 属性在构建时改成类名。
- **测试**：每个 JS 驱动的所有者由 `e2e/fx.spec.ts` 证明：首屏前没有请求该模块；隐藏或滚出视口后回调不再执行；模块 404 时页面照常；卸载后归零由 `web/packages/fx` 的单元测试证明（官网没有离开首屏的客户端路由）。现在覆盖海、入场、语言和深浅、各屏的加载与暂停、问答的定时器、页脚的切换和鲸、出发段，以及控制台登录页的海、鲨鱼凝成的瓦片体和标题解码（到达标记只用一次，直接打开时不解码；登录后计数归零，由 `e2e/fx-sign-in.spec.ts` 与 `e2e/fx-sign-in-solid.spec.ts` 证明），切换全程不得有 `securitypolicyviolation`。两种系统设置下照常播放由 `e2e/fx.spec.ts`（入场结束后海在两个受控时刻画出不同的画面、导览照常提供、登录按钮播放出发段）、`e2e/fx-sign-in.spec.ts`（登录页的海和瓦片体画出不同的画面、标题照常解码）和 `e2e/motion.spec.ts`（共用组件的图标悬停时移动、过渡时长不被压缩）证明。海的彩蛋由 `e2e/fx-eggs.spec.ts` 和 `director.test.ts`、`eggs.test.ts`、`terminal.test.ts`、`easter-eggs.test.tsx` 证明。`e2e/csp-deferred.spec.ts` 把官网滚到每一屏、叫出鲸、切语言和深浅、播完转场、走完登录，再打开控制台的每种浮层，全程不得有 `securitypolicyviolation` 和控制台错误。
- **接入屏的等距图**：`web/site/src/home/connect-figure.svg` 是单独的资源（`scripts/site-assets/connect-figure.ts` 从画板脚本切出，同时写 `connect-figure.gen.ts`：图的数字和画板自己的绘图函数），屏的代码到达后才取回，`DOMParser` 解析后 `importNode` 插入；画板里 2 处 `style` 属性在切出时去掉，由加载代码用 CSSOM 设置。它的规则由清单的 `inserted` 类前缀保留；脚本或引擎在运行时加的类和属性（`on`、`wh-lit`、`data-tab`）由清单的 `states` 声明，对应规则也保留。工具的配置文字和复制内容与控制台新建 key 的接入指南是同一份（`packages/ui/src/key-guide.ts`）：Codex 只复制配置文件，key 在终端设置；工具和桌面问答按 ARIA 标签页做：一行一个 Tab 停点，方向键和 Home、End 切换，卡片和答案是对应的面板；还没写出的 key 位置不进键盘顺序也不被朗读。每个工具的卡片按它的目标写：Codex 的文件里设 key 的终端命令保持为注释，卡片原样就是合法的文件；复制按钮的名称（读屏名和悬停提示）说明它复制什么（终端命令、配置文件、Base URL、代码、.env）。卡片上的文字就是命令本身的字符，手机上的折行交给 CSS，不往文字里加不换行空格或零宽字符，手动选取复制也能用；问答里工具设置的图让长地址换行而不裁掉，请求图的中间节点写站点名（过长时截断加省略号）。站点没有 API 地址时卡片和问答的图只说明地址不可用，不给缺地址的命令，复制按钮禁用；剪贴板拒绝时在卡片的文件名处写出「复制失败，请手动选择」；新的复制先清掉上一次的结果，页面离开视线时作废等待中的复制。等距图是装饰（`aria-hidden`），它表达的内容由标题、说明和卡片的文字给出。隐藏或滚出视口时故事停在原处（跑在共用帧循环上）。导览（`.tour`）从各屏的位置一路滑下去；菜单里的「这一页」列表滑到所选的屏。
- **进行中的交互**：首页宽屏的滚轮走惯性缓动（`behaviour.ts`，由共用帧循环驱动，停稳或被接管后立即退出循环），窄屏（手机、平板）的步骤屏与信任屏按正文实测高度排版（`useFitFrame`，`h + 96px`）。首页各屏异步或定时的动作（复制的结果和提示、工具切换的解码与卡片高度、问答连线、导览的下一步、鲸的一次游过）属于发起它的那次交互：同类的新交互、读者自己接管滚动（滚轮、触摸、按下、按键）、页面隐藏（导览、复制、鲸的召唤），都结束它并写入终态或清掉画面；导览或定位被结束时，进行中的平滑滚动停在原处；滑向某屏时，上方的屏变高由尺寸观察器跟着修正目标，直到读者接管或几秒后。切换工具同时结束复制提示。动画的每一步都检查它所在的时钟仍在用（`@axiom/fx` 的 `timeline` 在结束时通知等待中的步骤），旧动作不会挂到新时钟上。
- **鲸（彩蛋）**：在页面任意处键入 `deepseek`，或点首屏词条里的 deepseek，调用它；其他屏遇到 deepseek 模型时是一次偶遇（每次打开页面一次，页面打开十秒之后）。第一次调用时才加载 `@axiom/fx/whale`，它在运行中的海上游过，离开后卸载；海还没起来时不出现，页面收起时立即撤下，画布清空，点亮的条目和变薄的玻璃复原；代码还在路上时页面离开视线，这次召唤作废；游动中换深浅随之换色。首屏的词条是装饰（不被朗读），键盘用键入 deepseek 叫鲸。
- **海的彩蛋**：按设计稿的 eggs.js 和 MomentsLive 画板做（`@axiom/fx/eggs`，界面在 `site/src/home/easter-eggs.tsx`）。自动时刻（整点潮水，每小时 59 分）每次访问最多一个，打开后 10 秒内、按过控制 3 秒内、页面隐藏时不来；做了才有的每次访问各一次：开阔水面上停 4 秒鲨鱼游来、复制接入命令喂鱼、海底停 3 秒浮出「↑ 回到海面」（离开海底即收起）、画两圈起漩涡；状态不占名额：本地 22 点到 6 点深处有光点（深色主题下海至少压暗 12%），10 月 24 日鱼变成 0 和 1 共 24 秒。不在输入框里按 `/` 打开左下角的海底终端（对话框，输出朗读，最多 10 行，↑↓ 历史，Esc 关闭并还回焦点），键入 axiom 显示深度计，控制台打印鲨鱼，`window.axiom` 有 `dive`、`feed`、`help`、`whale`；whale 命令是有意召唤，照鲸自己的规矩。`ls` 列本站公开模型，公开接口没有延迟，`ping` 测浏览器到本站的一次往返；设计稿的线路事件要线路状态流，没有就不做。海没有的鱼食、漩涡、0 和 1、潮线、光点从设计稿的 ocean-react.js、moments.js、dive.js 移植，引擎不改；时刻播放时海保持运行，播完放开。
- **体积**：官网首屏脚本沿用前端性能指标；首屏以下的每个块 ≤50KB，延迟加载的动画与资源（如接入屏的等距图，作为单独的 `.svg` 取回）合计 ≤150KB，由 `web/scripts/budget.ts` 按构建清单的模块图（静态和动态导入）加总。

### 前端工程

- 代码在 `web/`，是一个 pnpm 工作区；结构、命令和必须遵守的规则见 [web/README.md](../web/README.md)。
- 页面只通过 HTTP 接口取数据；要用别的前端替换它，或对接某个约定（会话、CSRF、错误、分页、幂等、金额），读[前端接口指南](frontend-api.md)。
- 官网在公网监听的 `/`，控制台在 `/console/`，管理后台只在管理监听上。
- 控制台和管理后台构建时写入同一棵代码树构建出的程序的版本号（`axiom version` 输出的整行），之后定时和切回标签页时向 `GET /api/console/v1/version`（后台是 `/api/admin/v1/version`）询问正在运行的版本，不同就提示刷新。
- 内容安全策略只在 `web/vite.shared.ts` 定义一次。构建产物嵌入 Go 程序时（`just web-embed`），这个字符串一并写进嵌入的文件，Go 服务原样发送，不另写一份；缓存、压缩和回退的规则见[平台的「前端文件」](../internal/platform/README.md#前端文件)。
- 西文和数字用自己托管的 Instrument Sans，等宽用 JetBrains Mono，中文字体和分片见[字体](#字体)；字体族名只写在 `fonts.css`。
- **样式归组件（架构 B）**：保留 React、TanStack、i18n、`DataState` 这套骨架；设计稿的 CSS 近原样提成 CSS Modules（`*.module.css`），由一个组件独占：只能放在 `packages/ui/src/components/**`（产品组件）和 `site/src/home/**`（官网各屏），且只被同目录、同名的一个 TSX 导入，规则平铺、不嵌套（检查读不到嵌套和 `@scope` 这类 at 规则里的选择器，一律拒绝）。页面只组合组件，不写样式：应用代码（`console/`、`admin/`、`site/src`，`home/` 除外，以及 `packages/app`）不导入任何 CSS，TSX 里不写 `className`，`style` 只许 `--*` 自定义属性。全局 CSS 只有 `tokens.css`、`fonts.css` 和 `base.css`（`base.css` 是重置和文档基础）；颜色字面量只出现在 `tokens.css`。组件清单是「做新组件之前先查」的唯一出处，页面需要清单里没有的东西时停下来补组件，不在页面里自己造。
- **检查用棘轮落地**：新规则只对新组件和已迁移的模块生效；旧用法记在一份只减不增的基线里（`web/scripts/style-baseline.json`，按文件记数量，新文件必须为 0，数量减少时必须同时更新基线），迁移完的模块进基线的 `migrated` 列表、之后必须为 0；这些规则和源码里不写 HTML 与样式文本（见「动画」的 CSP 一条）由 `web/scripts/styles.ts` 检查，它的单元测试对整棵树跑一遍，所以随 `pnpm test` 进 CI；jscpd 把 CSS 也纳入重复检查。应用代码里没有 Tailwind 类名，Tailwind、`legacy.css` 和 `cn.ts` 已删除：全局 CSS 只有 `tokens.css`、`fonts.css` 和 `base.css`（浏览器默认样式的重置与文档基础，放在最低的 `@layer base`，组件自己的规则总能盖过它）。
- **写入策略**：由业务对象决定，不由面板决定（`EditPanel` 只负责呈现）。控制台契约没有 `PATCH`，`PUT` 是整体替换（见[前端接口指南](frontend-api.md)），所以默认**显式提交整个对象**：面板持有整个对象的草稿，「保存」时一次 `PUT`，保存期间锁住表单，失败时保留草稿并显示失败提示。只有这几类可以「改一项就生效」：请求体就是一个值的接口（服务商 key 的启停、扣费顺序）；带乐观锁的接口（路由默认、工作区路由默认带 `version`，路由预设带 `revision`，冲突 409 `stale_revision` 时重新读取再提示）；通知偏好，条件是写入串成队列，每次在上一次返回的对象上改一项再发。key、工作区、预算、命名预设和路由预设的规则编辑器必须显式提交；key 的启停是唯一例外：取最新的 key，只翻转 `disabled` 再 `PUT`，串行发送，撤销就是反向再做一次。后台一律走 `ChangeDialog`，不用即时保存。「可撤销」只给有反向操作的（停用、启用）；删除仍要确认，不做延迟发送的假撤销。
- **外壳与滚动**：由文档本身滚动，不做内部滚动容器：顶栏 `position: sticky` 贴顶，侧栏 sticky、高度为视口减顶栏、内部自己滚动，手机的底部标签 sticky 贴底，这样浏览器的滚动恢复、页内查找、空格翻页、手机地址栏收起和打印都照常。只有浮层内部滚动（对话框正文、右侧面板、底部面板、平板和手机上的详情面板）。路由跳转后焦点移到主区的 h1，且页面回到顶部；跳过链接指向主区。
- **截图对比（只在开发时用）**：`web/e2e/design/` 在一次性、断网、不留存储的浏览器上下文里执行设计稿自己的组件类，按画板对照产品页：视口按画板（1440、820、390；哪个场景对哪块画板写在 `web/e2e/design-map.ts`；画板没有的宽度不比：控制台各页三种宽度都有，官网首页各屏也是，官网模型页和登录类页面只有 1440、390），深浅两套，固定时区、语言、时钟、随机种子和就绪条件，参考页用未裁剪的源字体，canvas 比较固定种子的终态；产品裁决造成的差异按区域登记（每条写依据），不用整页阈值兜底，登记之外只允许抗锯齿量级的差异。没设 `AXIOM_DESIGN_DIR` 就跳过，不进 CI；设计稿文件不入库，只当数据读。源画板为中文，没有语言参数。英文对比把画板各区域的英文译文（`<Name>.en.ts`）换进参考画板，页面用英文；命名预设、模型页和登录类页面另按页面自己的文案改写。官网首页各屏只比中文（标题由画板脚本逐字拼成，译文换不进去），控制台的概览、用量、账单和通知页也只比中文（页面自己的英文文案与画板译文折行不同，账单的英文把人民币写作 CN¥）；它们的英文由 `gate.spec.ts` 查溢出和无障碍，截图人工核对。参考画板的中文字体按产品裁剪的字重轴绘制，模拟账户用画板演示账户的币种（人民币）；页面省掉、后文随之上移的区域，裁决标 `omitted`，参考画板里一并去掉。
- 官网、控制台登录页共用的动画引擎（海、方块拼形、标题解码）放在一个共享包里，只有一份；生命周期见[动画](#动画)。

logo 经同源公开接口按 SHA-256 提供，缓存一年；换图换地址，满足 `img-src 'self'`，不使用外部图床或 blob 地址。失败回退名称和标记，存储与清洗见[账户与租户](domains/accounts.md#站点)。

## 决策与理由

| 决策与约束 | 理由 |
|---|---|
| 后台按控制台风格用 `@axiom/ui` 的 CSS Modules 组件组成，旧组件保留原名、内部改用这些组件，页面再逐个换成新名 | 后台没有画板，逐个从画板切部件要等转换器、写手撞墙后再补，旧组件改内部一次就让所有后台页面换上控制台外观且不碰行为，剩下的只是去掉排版类名 |
| 样式只有 `@axiom/ui` 的 CSS Modules，不用 Tailwind | 工具类写在页面里使样式有两套来源并不断扩散；组件独占样式才能用棘轮检查 |
| 三个独立应用，共享设计系统；会话、登录、外壳归 `packages/app`，设计系统不依赖路由；路由集中手写，未找到页面用普通首页链接 | 公共页面与登录状态分离，共享业务不重复，错误页也可取到新版 |
| Biome `noJsxLiterals` 检查页面文案，属性文案由评审检查；认知复杂度 ≤15，圈复杂度 ≤12，函数 ≤60 行、文件 ≤500 行（不计空行注释，测试不限函数长度） | 与 Go 侧一致；`limits.ts` 按语法树词法单元计 JSX、字符串与模板内容，避免漏掉组件长度 |
| 圈复杂度计 if、循环、case、&&、`\|\|`、三元、catch、??，嵌套函数单算；knip 检查文件、依赖及包入口导出；jscpd 最少 50 词法单元，测试与语言命名空间表排除 | 认知复杂度不能替代分支数；共用包只给本仓库应用，无人引用的导出也是死代码 |
| 端到端由 Go `serveweb` 提供构建产物、模拟接口，只装无界面 Chromium；axe 每表只扫前 12 行、只取 violations，最坏数据溢出检查仍渲染全部行 | 测真实响应头、缓存、压缩；夹具行状态在前 11 行，避免重复 DOM 拖慢扫描，人工补键盘与读屏体验 |
| 列表选中和筛选写 URL：选行新增历史，方向键与搜索改写当前历史；默认值不写、非法值读默认；共用 `useUrlParams` / `useUrlSelection` | 刷新、后退和分享保留同一状态，不让方向键灌满历史 |
| `ListDetail` 固定行高窗口化、文档滚动；≥1024px 详情在旁、方向键改选中；更窄时模态面板让列表 inert，方向键仅移焦点，Enter/点按打开，关闭回原行 | 大列表只画邻近行；代价是窗口外行不可页内查找，窄屏不因方向键反复开面板 |
| 调用记录仍用游标加载更多，一页 50 行 | 顺着接口向后接，不为当前规模引入虚拟列表依赖 |
| 图表手写 SVG 形状与 HTML 文字，纵轴取 1/2/5 倍步长、计数最小 1，负数和非有限值画 0；左右键逐点朗读并附同数据隐藏表 | 简单图形无需图表库；轴、提示和数字经 format，金额标尺转十亿分之一文本再交 money，组件不做币种运算 |
| 收据打印隐藏导航、页头、版本提示，外壳 `print:block` 单列、强制浅色 | 去掉侧栏网格与深色配色才能正常打印，其他页面不加通用打印样式 |
| 手机侧栏用原生 dialog | 自带焦点限制与 Esc，不引入会注入 style、违反 CSP 的滚动锁 |
| 只靠 GET /session 判断登录，失效后登录并返回原页；Cookie HttpOnly，CSRF 仅内存 | 会话真相在服务端，浏览器不另存已登录状态 |
