# Axiom 隐私政策（示例）

生效日期：【生效日期】

## 引言与适用范围

1.1 本政策说明【运营主体名称】（下称“我们”）在提供 Axiom 网站、控制台、API 和相关服务（下称“本服务”）时，如何收集、使用、保存、共享和保护个人信息，以及您对这些信息享有哪些权利。

1.2 本政策适用于您访问或使用本服务时我们处理的个人信息。本政策不适用于上游模型提供方、第三方中转站、支付渠道、子站点运营者或其他第三方独立提供的服务；这些第三方有自己的隐私政策，您应另行阅读。

1.3 本政策中的“个人信息”指与已识别或可识别的自然人有关的各种信息，具体范围按【适用法律】确定。我们将按照合法、正当、必要和诚信的原则处理个人信息。

## 我们收集的信息

2.1 账户和身份信息：邮箱地址、密码哈希、第三方登录标识（如 GitHub、Google、LinuxDO 的账号标识）、通行密钥、两步验证密钥和恢复码、语言和时区偏好、邀请关系、角色和权限、邮箱验证状态、账户和工作区标识。

2.2 付款和账单信息：订单号、充值金额、付款币种、付款方式、支付渠道、渠道手续费、到账额度、退款和拒付记录、收据、发票信息（如您提供）。完整卡号、CVV、银行密码、支付密码和链上私钥由支付渠道处理，我们不收集、不保存。

2.3 API 使用信息：API key 的标识（前缀、末四位和哈希）、工作区、请求 ID、模型、端点或来源代号、每次尝试、用量、售价、成本、延迟、首字时间、错误类型、是否流式、是否缓存命中、是否免单、客户端应用、IP 地址、会话和子 agent 标识、应用归因头（如 HTTP-Referer、X-OpenRouter-Title、X-OpenRouter-Categories）、请求类别。

2.4 对话内容：您通过 API 提交的完整请求（包括消息、系统提示、工具定义、参数，以及图片、PDF、音频、文件等多模态内容），以及模型返回的完整回复、推理内容和工具调用。对话内容仅在平台开启保存时收集和保存；是否开启由平台统一决定，站点和账户不能单独关闭。未开启时，我们不保存正文，但仍会保存调用记录。

2.5 支持和通信信息：您与我们之间的邮件、工单、聊天记录、问题描述、附件，以及您对服务、账单、安全事件的反馈。

2.6 设备和日志信息：IP 地址、User-Agent、访问时间、访问的页面和操作、错误日志、安全事件、登录尝试、会话状态、CSRF 令牌、语言和主题偏好。运行日志不记录对话正文、API key 明文、上游 key、Cookie 或认证令牌。

2.7 Cookie 和本地存储：用于维持会话和防止跨站请求伪造的必要 Cookie，以及保存语言、主题和未完成表单状态的浏览器本地存储。我们不使用广告跟踪 Cookie，也不把您的个人信息出售给广告商。

## 我们如何使用信息

3.1 提供和运营本服务：认证、注册、路由、重试和回退、计费、预留和结算、退款、对账、账单和收据、模型和端点展示。

3.2 安全和反滥用：防止未授权访问、盗用 key、账户接管、欺诈、拒付、垃圾注册、限流绕过和其他滥用；进行安全审计、事件响应和争议调查。

3.3 客户支持：回答您的问题、排查故障、处理退款和投诉、恢复账户。

3.4 改进服务：统计和分析用量、性能、错误和容量，优化路由、端点质量、价格和用户体验。我们尽量使用聚合或去标识化的数据。

3.5 模型训练和改进：我们可能使用保存的对话内容改进模型或服务，但仅在取得适用法律要求的同意或具备其他合法依据时进行；在未取得必要同意前，不会将对话内容用于训练模型。每条调用记录会标明当时适用的训练许可状态。

3.6 法律和合规：遵守法律、法规、制裁、出口管制、执法或监管要求；执行本条款；保护我们、用户和第三方的权利、财产和安全。

3.7 通知：发送服务变更、安全事件、账单、退款、账户状态和重要政策更新。营销或促销信息会另行取得同意，您可以随时退订。

3.8 法律依据（在适用法律要求时）：履行合同、履行法律义务、保护您或他人的重大利益、我们的合法利益（在不影响您的权利和自由的前提下），以及您的同意。您可以随时撤回同意，但撤回不影响撤回前已经进行的处理。

## 对话内容和调用记录

4.1 调用记录（元数据）全部保存，不能关闭。调用记录用于计费、结算、对账、审计、安全、排障、争议处理和服务改进。调用记录不包含对话正文。

4.2 对话内容是否保存由平台统一决定。开启保存后，默认保留 90 天，后台可以调整，也可以长期保存；未开启时不保存正文。保存的内容包括完整请求、完整回复、工具调用，以及图片、文件等多模态内容。

4.3 保存的对话内容按账户隔离、加密存储，并按内容去重；去重指纹使用带账户密钥的 HMAC-SHA256，存储桶的访问者无法据此判断某段内容是否存在。API key、上游 key、Cookie、认证头和登录令牌不记录。

4.4 访问限制：任何用户、客户、站点管理员或普通员工都不能通过产品界面或普通 API 查看对话正文。只有平台负责人在受控流程下，经过两把独立密钥的两次签名、审计和加密导出，才能为追溯、安全、争议处理和在取得必要同意后改进或训练模型而访问保存的内容。导出会记录批准摘要、范围、条数、字节数、输出摘要和起止审计。

4.5 到期和回收：对话内容按“最后一次被引用的时间”判断是否到期；最后一个引用它的调用到期后，它才转冷或删除，由后台整理任务定期回收。调用记录按时间分区，热存默认 90 天后转入对象存储归档；账本、财务记录和审计记录按法律和内部政策长期保存。

4.6 响应缓存：如果站点开启响应缓存，缓存内容按独立条目加密保存，最长保留 24 小时，并纳入账户删除和导出范围；缓存不改变本政策对对话内容的访问限制。

## 共享、披露和委托处理

5.1 上游模型提供方：为完成您的请求，我们会把输入和必要的请求参数发送给实际服务的上游端点，包括官方 API、第三方中转站和 Axiom 自有号池。上游可能按其条款记录、保存、用于训练、用于改进或转售数据；我们不控制上游的数据实践。您可以按站点提供的端点属性、来源类别和预设选择或排除端点。

5.2 支付渠道和银行：为处理充值、退款、拒付和对账，我们会与支付渠道、银行和支付服务商共享必要的订单和付款信息。它们会按自己的隐私政策处理信息。

5.3 服务提供商：我们可能使用云服务、对象存储、邮件、监控、日志、安全和客服服务商。它们仅按我们的指示处理信息，并受保密和安全义务约束。我们不会允许它们把您的信息用于自己的营销。

5.4 关联方和子站点：如果您使用子站点，子站点运营者是其用户的管理者，我们会与其共享提供子站点服务所必需的信息；子站点运营者应遵守其自己的隐私政策和对您的承诺。我们与关联方共享信息时，要求其遵守本政策。

5.5 法律、执法和权利保护：在遵守法律的前提下，我们可能披露信息以响应传票、法院命令、监管要求、执法请求，或为了保护我们、用户、公众的权利、财产和安全。我们会审查请求的合法性和范围，并在法律允许时通知您。

5.6 业务转让：如果发生合并、收购、重组或资产转让，个人信息可能作为交易的一部分转移；我们会要求接收方继续受本政策约束，或取得您的同意。

5.7 我们不出售您的个人信息，也不为广告目的共享您的个人信息。

## Cookie 和本地存储

6.1 必要 Cookie：用于维持登录会话、区分站点和控制台、防止跨站请求伪造。禁用这些 Cookie 会导致无法登录或使用控制台。

6.2 本地存储：用于保存语言、主题、未完成表单的幂等键和页面偏好。您可以通过浏览器清除本地存储，但语言、主题和未完成状态会重置。

6.3 第三方登录：GitHub、Google、LinuxDO 等第三方登录可能在您的浏览器设置自己的 Cookie；它们的处理受各自隐私政策约束。

6.4 我们目前不使用广告或跨站跟踪技术。如果未来引入分析或营销工具，我们会更新本政策并依法取得同意。

## 保存期限

7.1 账户和身份信息：在账户存续期间保存；账户注销后，按法律要求保留必要记录，其余删除或匿名化。

7.2 调用记录：全部保存。热存默认 90 天（可调），之后归档到对象存储；归档对象不删除，以满足“调用记录全部保存”的产品要求。账本、财务记录和审计记录按法律和内部政策长期保存。

7.3 对话内容：仅在平台开启保存时保存；开启后默认 90 天（可调，也可长期保存），按最后引用时间到期回收。

7.4 支持和通信信息：按处理问题所需的时间保存，之后删除或匿名化，法律要求或争议需要时延长。

7.5 安全日志：按安全审计和事件响应所需的时间保存，通常不超过【日志保留期限】。

7.6 如果法律要求、争议、调查或执法需要，我们可能延长保存期限；延长期间仍按本政策保护信息。

## 安全

8.1 我们采取符合行业实践的技术和组织措施保护个人信息，包括：传输层加密；密码使用 argon2id 哈希；API key、上游 key 和支付凭证使用信封加密；密钥环和密钥轮换；数据库行级安全；最小权限和职责分离；操作审计；备份加密；访问控制和员工保密义务。

8.2 我们会定期审查安全措施，处理漏洞和事件。发生个人信息泄露、毁损、丢失或未经授权访问时，我们会按法律要求通知您和监管机构，并采取措施控制影响。

8.3 没有绝对安全。您应妥善保管密码、通行密钥、两步验证凭证、恢复码和 API key，不要在公共设备上保存会话，发现泄露立即通知我们。

## 您的权利

9.1 在适用法律范围内，您有权查阅、复制、更正、补充、删除您的个人信息，限制或反对处理，撤回同意，获取数据可携带副本，以及向监管机构投诉。

9.2 您可以通过控制台或【联系方式】提出请求。我们可能需要验证您的身份，并在法律允许的期限内回复。对于重复、过度或无理取闹的请求，我们可能收取合理费用或拒绝。

9.3 法律例外：如果信息涉及他人的权利、法律义务、财务记录、安全调查、争议或执法要求，我们可能无法删除或提供，但会说明理由。

9.4 对话正文不能通过产品界面或普通 API 查看。如果适用法律赋予您查阅、复制对话内容的权利，请通过【联系方式】提出；我们会在法律允许的范围内，通过受控流程核验身份并处理。

9.5 注销账户：您可以通过控制台或【联系方式】申请注销。注销后，您的个人信息按本政策处理，财务记录和依法应保留的记录继续保留；剩余额度按站点退款政策处理；同一邮箱可以重新注册，但会得到全新的账户。

9.6 营销退订：您可以随时通过邮件中的退订链接或【联系方式】退订营销信息。服务、安全和账单通知不属于营销，不能退订。

## 跨境传输

10.1 我们的服务器、服务提供商和上游模型提供方可能位于【国家或地区】。您的个人信息可能被传输到您所在国家或地区以外的地方处理。

10.2 我们会按【适用法律】的要求采取跨境传输保障措施，例如标准合同条款、数据传输协议、加密、去标识化或您的同意。您可以联系【联系方式】了解详情。

10.3 由于本服务的性质，您的请求会被发送到实际服务的上游端点，上游可能位于其他国家或地区。您应自行评估上游所在地区的数据保护水平是否满足您的要求。

## 未成年人

11.1 本服务不面向未成年人。我们不会有意收集未成年人的个人信息。如果您是未成年人，请在监护人同意和指导下使用，或不要使用本服务。

11.2 最低年龄要求为【最低年龄】。如果我们发现未经监护人同意收集了未成年人的个人信息，会尽快删除。监护人可以通过【联系方式】联系我们。

12.2 变更生效后，您继续使用本服务即表示您接受更新后的政策；如果您不接受，应停止使用本服务，并可以按退款政策申请退还未使用额度。

12.3 如果适用法律要求另行取得同意，我们会另行取得同意。
